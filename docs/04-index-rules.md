| # | 事项 | 决定 | 开发应呈现的结果 |
|---|---|---|---|
| 1 | 指数规则 | 保留权重 20/20/5/10/15、分级线 70/45、覆盖率 0.60、至少 5 条；**H、C 改为 [−1, 1]** | 能解释每个分项；证据不足不出总分 |

| 4 | 减值符号 | **loss_positive：损失为正、转回或净收益为负** | 历年符号可比，原始披露仍可追溯 |
| 5 | 假设与风险文档 | 见 `docs/05-assumptions-and-risks.md` | 披露时点、适用范围、风险与拒绝出分条件可查 |
| 6 | 计划书审核 | 提供可替换段落与审核清单 | 可先采用段落，不声称已逐段审完 |

> **H、C 改成 [−1, 1] 是本次最关键的修订，不能只改说明而沿用旧计算方式。**
> 旧稿五个分项都是 0–1，中性证据只能取 0.5，于是 H=C=0.5 会算出
> 50 + 20×0.5 + 20×0.5 = **70 分**——正好压在「一致性较高」的分界线上，
> 全中性的公司反而得分最高。改为 [−1, 1] 后全中性得 50 分。
>
> 上述权重是**透明的工程试行方案，不是文献证实的最优权重**。

## 二、资产减值损失：符号口径

`sign_convention = loss_positive`——**损失额为正**。这只改变系统的标准化表示，
不改变原始报表。同时 `profit_impact = -normalized_value`。

| 年报示例 | 原始数值 | 标准化减值损失 | 对利润影响 |
|---|---:|---:|---:|
| 2015 年，正数列示损失 | 1,486,729,666.32 | 1,486,729,666.32 | −1,486,729,666.32 |
| 2024 年，「损失以负号填列」 | −578,764,052.76 | 578,764,052.76 | −578,764,052.76 |

转换规则：

- 正数代表损失的旧式列报 → `normalized = raw`
- 明示「损失以负号填列」 → `normalized = -raw`
- **禁止使用绝对值**——允许转回的项目在新版列报里为正时，标准化应为负，表示净收益
- **不能凭年份硬编码**；以该表表头、行注及利润勾稽确定。无法确定时落 `needs_review`
- 保留原始值、原始行名、符号依据、单位、期间及来源页码

三条容易踩的边界：

1. **「资产减值损失」是期间损益；「减值准备」是余额**，两者不能互相替代
2. 固定资产、商誉等长期资产减值按适用准则**一般不得转回**，
   不能因为符号为负就自动解释成合法转回——先核查
3. 旧口径的资产减值可能包含后来单列信用减值的项目。
   **跨期趋势还须统一项目范围，不能只统一正负号**
4. **标准化不等于剔除减值。** 只有已批准的一次性调整才加回 EBIT，且只加回一次

## 三、主张与证据单元

一条可验证主张必须同时具备：**公司/业务对象、原句及页码、披露日、目标期间、
主题、指标、方向或数值目标、适用口径、判定结果和证据**。

- 同一句涉及不同指标**可拆分**；同一对象、期间、指标及目标的重复表述**须合并**
- **多个佐证指标不能重复算作多条有效观测**
- **历史兑现 H**：以前报告中的前瞻主张，其目标期间已结束、验证数据已公开
- **当期一致 C**：当前报告对已发生的经营结果作出的主张，与同期间事实比较
- **同一主张不得同时计入 H 和 C**
- 尚未到期的未来计划标记 `pending`，不作冲突
- **每条主张预先指定一个主判据**，必要时指定佐证指标，
  **不能看完结果后更换有利指标**

### 3.1 方向判定标度

| 判定 | s | 条件 |
|---|---:|---|
| 支持 supported | **+1** | 同口径直接证据满足目标或实质支持方向 |
| 无明显变化 neutral | **0** | 方向性主张对应的变化落在噪声区间 |
| 相悖 contradicted | **−1** | 直接证据超过阈值且方向相反，或明确数值目标未达成 |
| 待核查 needs_review | 不计分 | 只有间接代理、口径不一致、来源冲突或特殊事项解释未核清 |
| 不可验证 unverifiable | 不计分 | 未披露直接指标，或目标不够具体 |
| 不可比 incomparable | 不计分 | 并购、重组、政策变更、重述、周期、季节性 |

配套约束：

- 「努力、力争、拟、计划」等**意向不得等同保证承诺**——可跟踪目标完成情况，
  但**不能据此推断虚假陈述**
- **达到阈值边界按噪声处理；严格大于阈值才判为实质方向变化**

## 四、分项定义与公式

```
I_raw = 50 + 20H + 20C + 5R − 10P − 15Q
I     = min(100, max(0, I_raw))
```

| 项 | 定义 | 取值 |
|---|---|---|
| **H** | 历史有效主张 s 的等权平均 | **[−1, 1]** |
| **C** | 当期有效主张 s 的等权平均 | **[−1, 1]** |
| **R** | 风险披露检查项中「说明具体风险对象、作用路径且给出指标或事件依据」的项数 / 适用项数 | [0, 1] |
| **P** | 经人工确认缺乏可验证对象、期间或结果的实质经营表述数 / 去重后实质经营表述总数 | [0, 1] |
| **Q** | 已确认触发财务质量检查的独立事项数 / 已完成核验的适用检查项数 | [0, 1] |

### 4.1 R：钢铁初赛固定四项

需求及钢价 ｜ 原燃料成本 ｜ 环保及产能约束 ｜ 流动性及回款

> **不得以风险词频、文字长度计分。披露充分不代表风险小**——
> 词频高恰恰可能是模板化套话。

### 4.2 P 的排除项

**排除标题、法律声明及一般背景介绍**；重复句先去重。
**不能因正常模板文字或未兑现的长期愿景自动扣分。**

### 4.3 Q：初赛固定三项

1. 连续两个完整年度经营现金流净额为负，且这两个年度净利润均为正
2. 应收账款周转天数同比增加超过 **10 天**，
   **且**账龄超过一年的应收账款占比增加超过 **0.5 个百分点**
3. 存货周转天数同比增加超过 **10 天**，且同口径钢材销量下降超过 **1%**

> 以上是**需复核的风险筛查条件，不是造假判据**。

周转天数口径：

```
应收周转天数 = 平均应收账款账面净额 / 营业收入 × 365
存货周转天数 = 平均存货账面价值   / 营业成本 × 365
```

- 取**期初期末平均**，不用单一时点值
- 应收票据、应收款项融资**单独展示**；存在重大票据结算变化则先复核可比性
- 业务重组、口径变化或解释尚未核清**不得直接判定触发**

### 4.4 两条必须遵守的分母规则

**每个 Q 检查须逐条列明适用性、完成状态、证据和结论。
适用项未核完则 Q 不完整，不得当作未触发。**

**去重**：同一事项若已在 H / C 中扣分，Q 不再重复扣分——
保留该检查的已核验分母，重复事项不进入 Q 分子，并展示去重记录。

**展示义务**：所有分项展示分子、分母和来源。
**H/C 无观测时不得赋 0；R/P/Q 分母为 0 或尚未核完时不得凭空赋默认分。**

## 五、出分闸门与分级

**先建立完整的待验证主张清单，再开始匹配**——防止只挑容易验证的句子。

| 符号 | 含义 |
|---|---|
| **N** | 已到验证期、对象和目标可识别、且属于本期预定研究范围的**去重**主张数 |
| **n** | 其中已完成同口径验证，获得 supported / neutral / contradicted 的条数 |

**未披露直接数据、仍待复核的主张留在分母**；
**未到期的计划不进入分母，单独披露**。

### 5.1 闸门：四个条件全满足才出分

1. `n / N >= 0.60`
2. `n >= 5`
3. **H、C 各至少 1 条观测**
4. **R、P、Q 均可计算且核验完成**

未满足时输出 `insufficient_evidence`，指数为 **null**。
仍展示已核验主张，**不用 0 分或 50 分代替**。

> 5 条只是**演示最低门槛**；页面必须同时显示**样本数和覆盖率**，
> 不能展示虚构的统计置信度。

### 5.2 分级

| 分值（按未四舍五入值分级） | 页面文案 |
|---|---|
| I ≥ 70 | 已核验样本的一致性支持较强 |
| 45 ≤ I < 70 | 支持与风险并存，需关注 |
| I < 45 | 已核验样本支持较弱，优先复核 |

> **这不是诚信评分、欺诈概率或收益预测。
> 公司间样本主题和期间不一致时不直接排名。**

## 六、重要性与噪声阈值

批准 `narrative.min_rel_change = 0.01`，
**但仅限金额、数量类指标，不能用于所有指标。**

| 类型 | 初赛规则 | 配置键 |
|---|---|---|
| **金额 / 数量** | 基期为正且非接近零时取相对变化；绝对变化率 **≤ 1% 为噪声** | `narrative.min_rel_change` |
| **毛利率、费用率、占比等比例** | 本期比例 − 基期比例；绝对变化 **≤ 0.5 个百分点为噪声** | `narrative.min_ratio_change`（前提：比例以 0–1 存储） |
| **周转天数** | 绝对变化 **≤ 3 天为噪声** | `narrative.min_days_change` |
| **产能利用率方向** | 绝对变化 **≤ 1 个百分点为噪声** | `narrative.min_utilization_change` |
| **明确数值目标** | 按原目标上下限、口径和披露精度核验 | **不套用统一容差** |

### 6.1 验收用例

- 毛利率 10.00% → 9.96%，下降 **0.04 个百分点** → 判**无明显变化**，不判冲突
- 毛利率 10.00% → 9.40%，下降 **0.60 个百分点** → 才有实质下降信号；
  仍须符合主张的直接判据
- 收入 100 → 100.8，增长 **0.8%** → 方向性「增长」标为无明显变化，
  **不能判成反向冲突**
- 「收入增长至少 5%」而实际增长 **4%** → **应判目标未达成**，
  不因差距只有 1 个百分点而忽略

### 6.2 边界规则

- **不将 1% 称为审计重要性水平**。它仅是本项目初赛的变化过滤参数
- 基期 ≤ 0，或基期绝对额不超过同期营业收入 **0.1%** 时，
  不自动计算金额增长方向，改用同口径利润率/现金流率变化或人工核验
- 数量类基期接近零由**指标预设的最小有效量**判断，未设定则人工复核
- 披露四舍五入误差超过默认阈值时，采用更大的可解释误差界限；
  边界无法判明时 `needs_review`
- 明确目标中的「约」「左右」如无公开容差，
  **仅显示实际偏差并复核，不擅自认定完成或未完成**
- 比例字段若存为百分数 10.00 而非 0.10，**须先换算再比较**
  （存储约定：本项目一律以 0–1 存储）

## 六·补、年度经营计划里的绝对量目标

> **出处：会计 K 2026-10-01 答复**（随《给会计的材料-20261001》第七节发出，
> 答复文件 `给会计的材料-20261001-人工复核/08_第七节答复.txt`）。
> 这一节是转写，**冲突时以答复原文为准**。
> 落地代码：`app/engine/claim_match.py::_judge_absolute_target`。

年报「公司未来发展的展望」里有一类句子，一句话塞五六个目标：

> 2018年，宝钢股份计划产铁4563万吨、产钢4737万吨、销售商品坯材4568万吨、
> 营业总收入2786亿元、**营业成本2420亿元**。

### 6·补.1 单位换算（问 8-1）

**可以。** 目标中的「亿元」统一换算为财务事实库的「百万元」，
按 **1 亿元 = 100 百万元**。

系统**同时保留原始数值、原始单位、换算因子和标准化数值**，
避免把换算后的数值当成原始披露。

> 落地：`claim_match.target_unit` / `unit_factor` / `target_millions`
> 三列留痕，原始数值与原始单位在 `claim` 表上。
> ⚠ **只有金额类给了换算因子。** 吨 / 万吨 的换算法（事实库存的是吨
> 还是万吨）没有定，所以引擎对它们**不给因子、不算偏差**，转人工复核——
> 不猜一个看起来合理的数。

### 6·补.2 达成方向（问 8-2）

| 目标类型 | 达成 | 未达成 |
|---|---|---|
| **营业成本**（越小越好） | 实际成本**不高于**计划成本 | 实际成本**高于**计划成本 |
| **营业总收入**（越大越好） | 实际收入**不低于**计划收入 | 实际收入**低于**计划收入 |

- 这里的「达成 / 未达成」**只表示与公开年度计划的数值比较**，
  **不等同于虚假披露或经营失败**
- 目标含「约」「左右」等模糊表述时，**先标 `needs_review`，
  不擅自套用固定容差**

> 落地：方向取自 `metric_definition.sign_convention`（本文件 §二 已定的字段），
> 不另立一套。`positive_is_good` → 越大越好；`negative_is_good` → 越小越好；
> `neutral` → 方向判不了，只报偏差、不出参考结论。

### 6·补.3 要不要按产量调整（问 8-3，最要紧的一条）

**采用第四种做法**：按同口径、同范围的单位成本并结合固定成本和变动成本
进行产量调整；**只有在成本行为和产量口径足够清楚时**，才把实际成本与
产量调整后的计划基准比较。

具体规则：

1. 先核对产铁、产钢、销售商品坯材与营业成本的**业务范围和期间**
2. **优先比较单位成本**（例如同口径每吨钢材成本），并区分固定成本与
   随产量变化的成本
3. 如果**只有总成本、没有可靠的成本结构或产品组合信息**，
   **不能简单按产量同比例缩放，也不能直接判「未达成」**，
   应标记 `incomparable` 或 `needs_review`
4. **未经调整的总额差异可以展示为「原始计划偏差」，
   但不进入 H 的支持/相悖判定**

答复末句原话：

> 因此，2018 年营业成本目标不应仅用 2,590.85 亿元对 2,420 亿元
> 直接判定未达成；应先完成同口径、产量和成本结构复核。

> **落地后的实际行为**（见 `claim_match._judge_absolute_target`）：
> 换算并算出「原始计划偏差」展示给人看，按 6·补.2 给出**参考结论**，
> 但 `verdict` 一律是 `needs_review`。**因此这一批主张不进 H。**
> 数据库层面用 CHECK 钉死了这件事：
> `plan_variance IS NULL OR verdict = 'needs_review'`——
> 想把它接进计分，写不进去。
>
> 另有一道更上游的闸门：如果那个数字**没有和主判据的别名相邻**
> （抽取时退回取「第一个带单位的数」），说明这句话的数与该指标
> 在文字上没有关联，**连偏差都不算**。实测撞到过 5 条把资本开支
> 当成营业成本目标的（「预算安排固定资产投资资金239.2亿元」）。

## 七、主题词表的会计判据

| 主张主题 | 主要核验指标 | 佐证指标 | **禁止的简化推断** |
|---|---|---|---|
| **降本增效** | 降本：同产品同工艺单位生产/销售成本；增效：主张明确指向的费用率、能耗或效率指标 | 毛利率、期间费用率 | **毛利率下降不等于降本失败，售价下降也会压缩毛利率** |
| **产品结构升级** | 高端/重点产品销量占比或收入占比，按主张选择且前后定义一致 | 分产品毛利率、售价、客户结构 | **整体毛利率不能单独证明或否定产品升级** |
| **需求与产销** | 销量主张对应钢材销量；产量主张对应产量；订单主张对应同口径订单 | 营业收入、售价、库存 | 收入下降可能由价格造成；**产量不能代替销量验证需求** |
| **回款改善** | 回款速度：DSO；逾期回收：逾期/账龄及收回额；现金回收：销售商品提供劳务收到的现金及对应收入 | CFO、CFO/收入 | **CFO 下滑不能单独否定回款**，存货采购与应付结算也会影响 CFO |
| **产能释放** | 同产品产量、已投产且时间加权的有效产能、同口径利用率 | 在建工程转固、产销匹配 | **转固增加不等于产能已经释放** |

> 第五类（产能释放）为会计方**建议补充**，尚未提供实际词表。
> 系统的做法是：词表保留但标 `unverifiable` 并写明原因，
> **不冒充已审过，也不用代理指标硬判**。

其它约束：

- 「降本」与「增效」、「需求」与「产销」内部**仍须按具体原句选择指标，
  不应整类共用一个字段**
- 销售收现/收入受增值税、预收款和票据结算影响，**只在口径一致时比较**
- **主判据未披露：标记不可验证或待核查，
  不能降级用代理指标直接作出冲突结论**
- 周期钢价、原料价格、季节性、并购和产品组合变化必须检查；
  **解释有证据才展示，不能编造原因**

## 八、向估值情景传导

> **初赛默认「指数提示 + 人工确认经营假设」，
> 不把分数换算成概率或折现率。**

| 结果 | 工作台动作 | 估值动作 |
|---|---|---|
| **≥ 70** | 展示支持证据及仍存在的风险 | 保留原有情景；**不得自动提高增长率** |
| **45–70（不含 70）** | 展示争议项与经营假设敏感性 | **请求确认相关假设，不自动改值** |
| **< 45** | 优先展开压力情景和反证条件 | **人工确认具体经营参数后重算** |
| **不足以出分** | 展示缺口及补资料入口 | **不发生由指数驱动的估值调整** |

- **传导只针对有直接证据的经营参数**：销量影响收入、单位成本影响毛利及 EBIT、
  回款天数影响应收与营运资本
- 每次调整记录旧值、新值、依据、批准人和规则版本
- **同一风险不能同时压低收入、利润率并抬高 WACC**（重复惩罚）
- **WACC 和永续增长率需独立依据；不得仅因叙事指数低而修改**
- 情景权重如另行设置，应**标注为研究者主观假设而非模型估计概率**

> ⚠ 本节与 `docs/03-valuation-rules.md` §八 冲突。按本文开头的优先级声明，
> **以本节为准**。`docs/03` §八 已加注说明。

## 九、验收案例

| 案例 | 预期结果 |
|---|---|
| H=0、C=0、R=0、P=0、Q=0，且各项确有可计算证据 | **I = 50**，不能按全缺失模拟 |
| H=1、C=1、R=1、P=0、Q=0 | **I = 95** |
| H=−1、C=−1、R=0、P=1、Q=1 | 原值 −15，**截断为 0** |
| 6/10 条有效，H/C 均有观测且其它分项完整 | 覆盖闸门**通过** |
| 5/10 条有效 | **不通过**覆盖闸门 |
| 4/5 条有效 | **不通过**最少观测闸门 |
| 全部都是本期主张，历史没有可验证观测 | 展示 C，**不输出完整指数** |
| 毛利率下降 0.04 个百分点，主张为毛利改善 | **neutral，不是 contradicted** |
| 仅 CFO 下降，主张为回款改善 | **不足以据此判冲突** |

以上九条已实现为自动化测试（`backend/tests/unit/engine/`）。

### 验证边界

- 先用 **30–50 条**双人标注主张检验方向判断与一致率，分歧人工裁定
- 按**披露日期**切分开发与留出样本，**同一主张不能跨集合**
- 同时报告**覆盖率、已判定样本准确率及冲突识别的 precision / recall**；
  样本少时展示逐条结果，**不宣称显著提升收益预测**
- **权重、分级线及阈值后续须做敏感性分析；修改需升版本，
  不可为演示样本临时调参**

## 十、实施顺序

1. 先对齐 H/C 定义、阈值单位及缺失状态，再实现指数；**不得仅抄五个权重**
2. 替换主题到指标的判据表；**重跑现有冲突，逐条保留/撤销并记录原因**
3. 完成减值符号标准化及转换用例，再跑跨年趋势；会计范围变化另外标注
4. 通过覆盖率、五条观测、边界值、未来期间及中性变化用例后，接入演示页面
5. 用 **30–50 条**人工主张样本检验；展示覆盖率、误判案例及限制，
   **不宣传未经验证的预测准确率**
6. 计划书和完整配置到位后逐项核验

> 开发方须将现有 H/C 的旧定义迁移到本版，逐项核对配置键及枚举；
> **旧分数不能与本版直接比较。**
